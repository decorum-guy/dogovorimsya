# Договоримся

**Оценки обсуждаются.**

Приватное романтическое PWA для пары: оба ставят друг другу честные оценки за моменты, прикрепляют фотографии, обсуждают отзывы и сохраняют историю правок. Тон — от нежности и бумажных сердечек до космического абсурда, рожек, огня и крепких слов. Оцениваем момент, а не человека.

## Текущий статус

Проект **реализован и работает в production**, включая взаимные оценки и фотографии в комментариях. Это существующее приложение, а не заготовка или предложение выбрать стек.

## Что уже работает

- **Два закрытых профиля.** Регистрация по коду: один код создаёт один аккаунт, затем служит для восстановления его пароля. Имена, аватары, смена пароля, серверная сессия на 180 дней с продлением при использовании.
- **Взаимные оценки 0.0–5.0 с шагом 0.1.** Заголовок, текст и до пяти фото. Адресата выбирает сервер — второй участник. Каждый правит только свои отзывы; админка кодов и паролей доступна владельцу отдельно.
- **История.** Балл, заголовок, текст, дата/время, фотографии и объяснение правки сохраняются в версиях. Устаревшая вкладка не перетирает новую редакцию. Смена балла видна как «4.9 → 5.0».
- **Дата и время.** При публикации определяются сервером по Москве; изменить их можно в редакторе. Исходное техническое время создания не переписывается.
- **Лента «Тебе / От тебя / Всё».** По умолчанию входящие, после создания — исходящие. На карточках и в подробностях видны автор и адресат. Прежние отзывы автора находятся в «От тебя». Поиск на широких экранах, фильтры по настроению и правкам.
- **Комментарии с фото.** Оба могут добавлять до пяти фото с отдельными необязательными подписями, в том числе без общего текста; редактировать свои комментарии и вложения. Новые комментарии проверяются каждые пять секунд, пока обсуждение открыто и приложение видно.
- **Реакции и личное избранное.** Четыре реакции, звёздочка на карточке и в отзыве. В избранном собственный фильтр направления, по умолчанию «Всё».
- **«Мы вдвоём».** Дни с регистрации второго профиля, общие моменты/фото/комментарии/реакции, избранное каждого и совпадения. Полученные и написанные отзывы, средний балл, пятёрки и распределение оценок отдельно для каждого получателя.
- **Дизайн.** Тёплая бумага, сливовые чернила, локальные Manrope / Playfair Display / Caveat. Пять диапазонов настроения, по пять автоматических наборов мелких деталей: скотч, сердечки, звёзды и рожицы. Оформление не нужно выбирать вручную; единицы получают огненный стиль.
- **760 приветствий.** По 380 для каждого профиля, включая по 86 с явным матом. В пределах браузера весь перемешанный пул проходит до повторения; ререндер и обновление ленты фразу не меняют. Все подготовленные фразы сохранены.
- **PWA для iPhone.** Манифест, иконки, standalone-режим, safe-area, публичный офлайн-экран и обновление главной/избранного жестом вниз с отпусканием. Есть кнопка обновления.
- **Web Push.** Новые отзывы и изменения балла идут адресату записи; комментарии, избранное и реакции — другому участнику. У каждого подключение устройств, категории, общий выключатель, пауза и запрос беззвучной доставки.
- **Надёжность и приватность.** Повтор после потерянного ответа не дублирует создание, старые ответы не затирают свежие данные, черновики защищены от случайного закрытия. Фото и API требуют сессию, EXIF удаляется, приватные ответы не попадают в кеш service worker.

### Локальное демо без личных данных

Нужен Node.js **24+** и npm. Production-образ использует Node.js 24.

```sh
git clone --branch codex/mvp https://github.com/decorum-guy/dogovorimsya.git
cd dogovorimsya
npm ci
npm run demo
```

Открыть `http://localhost:3000`. Демо использует только вымышленные записи в `data/demo`, включая оценки в обе стороны. В «Мы вдвоём» можно переключить профиль. Оно работает только на loopback и запрещено в production. Если браузер сохранил демосессию, может открыться ранее выбранный профиль.

Галерея деталей — `http://localhost:3000/design`; `?tone=inferno` показывает огненную серию, остальные значения: `gold`, `rose`, `paper`, `ember`. Это демонстрация автоматических деталей, а не выбор дизайна пользователем.

### Новая приватная база локально

Только для нового локального окружения, после `npm ci`:

```sh
cp .env.example .env
npm run accounts
npm run dev
```

Команда интерактивно создаёт администратора. После входа в «Доступ» выдать приглашение второму участнику. Пароли не передаются аргументами. Для первого входа на пустой базе есть `npm run accounts -- bootstrap`: создаёт временный логин `owner` и один раз показывает код восстановления. Это способ первоначальной настройки, а не описание действующих аккаунтов production.

Сброс из интерактивного терминала: `npm run accounts -- reset reviewer` или `recipient`; он отзывает сессии соответствующего профиля. Подробности восстановления — [развёртывание](docs/deployment.md).

### Проверки

```sh
npm test
npm run build
```

Тесты используют временные SQLite и вымышленные данные. Dockerfile также запускает тесты и сборку. GitHub Actions workflow и автоматический деплой в репозитории не настроены.

## Границы

Это приложение для одной пары, не публичный сервис и не система формальных апелляций. Личный журнал не доступен офлайн; несохранённый черновик хранится только в памяти. HEIC зависит от декодеров sharp/libvips. Установка, клавиатура, жест и доставка push на настоящем iPhone требуют проверки на устройстве; браузерная мобильная проверка её не заменяет. Звуком уведомлений управляет iOS. Подробности и открытые работы — [docs/status.md](docs/status.md).

Реальные имена, отзывы, фотографии, коды, ключи, `.env`, БД и резервные копии в Git не попадают.
